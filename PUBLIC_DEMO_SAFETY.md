# Public demo safety checklist

- [x] No `st.file_uploader` call in the public app.
- [x] Public app loads only bundled fictional sample files.
- [x] No credentials, API keys, or secrets are required.
- [x] Decision history is session-only and exportable.
- [x] Privacy and prototype limits are shown in the app.
- [ ] Test the deployed URL in a private browser window.
- [ ] Verify sample-only behavior after deployment.
- [ ] Do not invite live customer data until security architecture and testing are complete.
